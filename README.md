# WorldRefiner

## QUICKSTART

### Requirements:
1. Install `Node.js` if you don't already have it
2. Open *Command Terminal* at your project's root (i.e. `path/to/WorldRefiner`)
3. Run this command: `npm install`

The main file to start the app is `start-electron` batch file. 

You can do the following to start the app:
1. Manually run `start-electron`
2. Create a shortcut to that batch file and place the shortcut you deem most convenient.





## FAQ:
Q: The app popped up, but I only see a blank white screen.
A: Wait at least 5 minutes. It's setting up your local data source. If it's still blank after 5 minutes, create a ticket.
